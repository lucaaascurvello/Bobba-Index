# 💀 Bobba Index
### O universo Habbo, indexado.

Explore jogadores, perfis públicos e informações do universo Habbo em uma plataforma independente criada para reunir a nostalgia da comunidade com a tecnologia.

## ✨ Sobre o projeto

O **Bobba Index** é um projeto independente que nasceu da ideia de tornar a exploração do universo Habbo mais acessível, organizada e intuitiva.

A proposta é desenvolver uma plataforma que permita consultar informações públicas de jogadores e explorar diferentes aspectos do universo Habbo, combinando uma interface moderna com fontes de dados disponíveis publicamente.

Mais do que uma ferramenta de consulta, o projeto busca unir tecnologia, experimentação e nostalgia em uma experiência desenvolvida para a comunidade.

🔗 **Acesse:** [bobba-hub-explorer.lovable.app](https://bobba-index.lovable.app/)

## 🚀 Funcionalidades

O projeto foi concebido para reunir diferentes recursos de exploração do Habbo em um só lugar.

- 🔍 **Busca de jogadores:** pesquisa de usuários do Habbo a partir das informações disponíveis nas fontes integradas.
- 👤 **Perfis públicos:** consulta e visualização de informações públicas dos jogadores.
- 🧩 **Exploração de emblemas:** estrutura dedicada à descoberta e consulta de emblemas.
- 🏨 **Suporte a hotéis:** arquitetura planejada para permitir a expansão para outros hotéis do Habbo.
- 🌙 **Interface dark:** experiência visual inspirada em plataformas modernas de tecnologia, com identidade própria.
- 📱 **Experiência responsiva:** proposta de navegação adaptável a diferentes tamanhos de tela.

> A disponibilidade de cada recurso depende dos endpoints, das permissões e dos dados efetivamente fornecidos pelas fontes consultadas.

## 🎨 Identidade visual

O Bobba Index combina uma estética tecnológica com referências sutis ao universo Habbo.

- **Dark mode:** fundo grafite e superfícies escuras.
- **Roxo elétrico:** cor de destaque para ações e elementos interativos.
- **Interface minimalista:** hierarquia visual clara e componentes organizados.
- **Pixel art:** referências visuais ao universo dos jogos, utilizadas de forma pontual.
- **Experiência moderna:** foco em legibilidade, navegação e consistência visual.

A intenção é construir uma ferramenta com aparência de produto digital, preservando a personalidade e a nostalgia da comunidade Habbo.

## 🛠️ Tecnologias

O projeto utiliza uma base moderna de desenvolvimento web, com tecnologias como:

- React
- TypeScript
- Vite
- Tailwind CSS
- Componentes de interface reutilizáveis
- Lovable para desenvolvimento e prototipação

A integração com dados do Habbo depende da disponibilidade e compatibilidade das fontes públicas utilizadas pelo projeto.

## 🧠 Objetivos do projeto

O Bobba Index também funciona como um laboratório de aprendizado e desenvolvimento, explorando possibilidades como:

- Integração com APIs públicas.
- Organização e apresentação de dados.
- Desenvolvimento de interfaces responsivas.
- Arquitetura de aplicações web.
- Prototipação rápida com ferramentas de desenvolvimento assistido por IA.
- Criação de experiências digitais voltadas a comunidades online.

O projeto evolui conforme as possibilidades técnicas e a disponibilidade dos dados consultados.

## 🔒 Transparência e limitações

O Bobba Index utiliza fontes públicas de dados quando disponíveis. Isso não significa que todas as informações do Habbo possam ser consultadas.

- Alguns dados podem não estar disponíveis publicamente.
- A API pode apresentar limitações, indisponibilidade ou restrições de acesso.
- Informações de perfis podem estar incompletas.
- A disponibilidade dos recursos pode variar entre hotéis.

O projeto não solicita senhas ou credenciais de acesso ao Habbo.
